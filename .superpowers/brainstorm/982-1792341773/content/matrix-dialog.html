C · Fill while you build

The dialog itself is a small editable grid: type values now, add rows/columns as you go, leave cells empty. Everything you type lands in the equation exactly as written.

You can click more than one to explore — I'll also fix matrix brackets dropping out while you edit, whichever option you pick.
